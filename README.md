# JARVIS · Personal Space

우주 테마의 개인 AI 비서 초기 버전. Python 3.9 이상과 웹 브라우저가 필요합니다. 추가 Python 패키지는 없습니다.

## 맥에서 실행

저장소를 다운로드하고 폴더에서 실행합니다.

```bash
python3 app.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 종료는 터미널에서 Ctrl+C.

## 현재 기능

- 반응형 우주 테마 화면
- 기억 저장, 목록, 삭제 (로컬 SQLite)
- macOS 내장 `say`로 시스템 기본 음성 재생 및 정지
- 음성 설정은 macOS 시스템 설정에서 변경합니다. 한국어를 읽으려면 한국어 시스템 음성을 선택하세요.

## 데이터

기억은 실행 중인 컴퓨터의 `data/jarvis.sqlite3`에 저장되며 Git에서 제외됩니다. GitHub에는 코드만 올리세요. 앱은 127.0.0.1에만 접속을 허용합니다. 공개 호스팅용 서버가 아닙니다.

외부 DB 연결은 아직 구현되지 않았습니다. GitHub에 DB 서비스가 연결되어 있어도 앱에서 사용하는 연결 정보, 테이블 구조, 사용자 인증은 별도로 확인해야 합니다. 비밀키나 개인 정보는 저장소에 커밋하지 마세요.
